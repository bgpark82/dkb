I/O 작업(네트워크 통신, 파일 접근 등)은 대부분의 시간을 데이터가 오기를 기다리는 데(waiting) 소비합니다. 
이 시간 동안 스레드는 아무것도 하지 않고 대기 상태에 머무르게 되는데, 는 이러한 비효율성을 해결해 줍니다.Dispatchers.IO

I/O 작업의 특성과 문제점
일반적으로 I/O 작업은 다음과 같은 특징을 가집니다.

블로킹: I/O 작업이 완료될 때까지 해당 스레드는 다른 작업을 수행할 수 없습니다.

긴 대기 시간: CPU 연산과 달리, I/O 작업은 외부 장치나 네트워크의 응답을 기다려야 하므로 대기 시간이 길 수 있습니다.
